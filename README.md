# Text to Own Handwriting

Convert typed text into realistic handwriting and download as PNG or PDF.

## Features

- 5 built-in handwriting styles + upload your own font
- Customize ink color, font size, ruled lines, and margin
- Auto multi-page flow
- Export as PNG or PDF

## Dev Setup

```bash
pnpm install
pnpm dev
```
